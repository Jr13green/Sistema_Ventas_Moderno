# SistemaVentas Web Dashboard

Dashboard web React 18 + TypeScript para el Sistema de Ventas.

## Stack

- React 18 + TypeScript
- Material-UI (MUI)
- Redux Toolkit
- Chart.js
- React Router v6
- Vite

## Instalación

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- Dashboard con gráficas en tiempo real
- Gestión de ventas con DataGrid
- Reportes visuales (Bar, Line charts)
- Autenticación JWT
- Panel de configuración
